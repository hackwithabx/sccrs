🔑 Module 1: Secrets Scanner

Detect hardcoded credentials, API keys, and tokens before they reach production.

How to Use

  • Navigate to ShieldX → Modules
  • Click "Open Scanner" on the Secrets Scanner card
  • Paste your source code, .env files, config files, or any text
  • Click "Run Scan"
  • Review findings with confidence levels (High / Medium / Low)

Demo users: Click "Run Demo Scan" to see sample results with a pre-loaded .env file without pasting any code.

What It Detects (20+ Patterns)

AWS Access Keys GitHub Tokens Private Keys (RSA/EC/PGP) Stripe API Keys Slack Tokens Google API Keys JWT Tokens npm Tokens Database Connection Strings Docker Registry Auth SendGrid / Twilio / Mailgun Generic Passwords in Code Internal IP Addresses

Confidence Scoring

Uses Shannon entropy analysis to reduce false positives. High-entropy strings (random-looking) get higher confidence scores. Placeholder values (test_, example_, dummy) are automatically filtered out.

🌐 Module 3: API Security Scanner

OWASP API Security Top 10 (2023) compliance testing for any publicly accessible API endpoint.

How to Use

  • Open API Security Scanner from the Modules tab
  • Enter the target URL (e.g., https://api.yourcompany.com/v1/health)
  • Click "Run Scan"
  • Review security headers, CORS, auth, and OWASP compliance

Note: Only scan APIs that you own or have written permission to test. The scanner makes real HTTP requests to the target.

What Gets Tested

  • Security Headers — X-Content-Type-Options, X-Frame-Options, HSTS, CSP, Referrer-Policy
  • CORS Policy — Access-Control-Allow-Origin, credentials handling
  • Authentication — Auth header requirements, exposed endpoints
  • Server Info Leak — Server header, X-Powered-By exposure
  • OWASP API Top 10 — Broken Object Level Auth, Broken Authentication, Excessive Data Exposure, and more

Security Score

Each API gets a 0–10 security score based on weighted pass/fail results. A score of 7+ indicates good security posture. Below 4 requires immediate attention.

🔒 Privacy & Security Architecture

Your code never touches our disk. Here's how we keep it safe.

What We Store

✓ StoredScan results (scores, findings, severity counts)
✓ StoredUser account data (email, name, plan)
✓ StoredAlert configurations
✓ StoredAPI key hashes (bcrypt)

What We Do NOT Store

✗ NeverSource code, config files, or log data
✗ NeverPasswords in plaintext
✗ NeverAPI keys in plaintext
✗ NeverThird-party telemetry or analytics

Security Controls

  • HTTPS Everywhere — TLS 1.3 for all connections
  • JWT Authentication — Signed tokens, no session storage
  • Rate Limiting — Per-IP and per-user limits on all endpoints
  • Input Validation — Size limits: 50KB (free), 500KB (paid), 1MB (logs)
  • SSRF Protection — Blocks scans targeting private/internal IPs
  • CORS — Strict same-origin policy
  • Secure Hashing — bcrypt for passwords, SHA-256 for API keys
  • Webhook Verification — Razorpay webhooks use timingSafeEqual

Frequently Asked Questions

Q: Is my source code stored on your servers?

No. All scans happen in-memory. Your code is never written to disk or logged. Only scan results (scores, finding summaries) are stored.

Q: Can ShieldX replace our existing security tools?

For many teams, yes. ShieldX covers secrets detection, dependency scanning, API testing, cloud auditing, and log analysis — that's typically 4–5 separate tools.

Q: How accurate is the scanning?

The secrets scanner uses regex + Shannon entropy to minimize false positives. Dependencies are checked against OSV.dev (Google's real CVE database). API scans make real HTTP requests to test your endpoints.

Q: What happens if I cancel my plan?

Your access continues until the end of the billing period. Scan history is retained. You can re-subscribe at any time.

Q: Can I use ShieldX in my CI/CD pipeline?

Yes. Enterprise users get CI/CD pipeline gate integration. Generate an API key and add a cURL command to your GitHub Actions, GitLab CI, or Jenkins pipeline.

Q: Does ShieldX scan private repositories?

ShieldX doesn't connect to GitHub/GitLab directly. You paste code or use the API to submit code for scanning. This means it works with any repository, private or public.

Q: What compliance standards does it help with?

ShieldX helps with OWASP Top 10, OWASP API Top 10, CIS Benchmarks (cloud), and general DevSecOps best practices. It's not a compliance certification tool.

Q: How do I get support?

Email support for all plans. Enterprise gets priority support with dedicated contact. Visit securecodereviews.com/contact.
